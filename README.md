## 📖 Overview

**Island Escape 3D — The Lost Treasure** is a 3D web-based adventure game designed around exploration, discovery, puzzle solving, and treasure hunting.

The player begins on a mysterious tropical island and must explore different environments, discover hidden collectibles, solve ancient mechanisms, survive environmental hazards, and progress toward the final treasure temple.

The project was developed as a university web-game assignment and extended into a complete playable 3D experience using modern browser technologies.

---

## 🎯 Project Goals

The main goals of this project were to:

- Build a complete playable 3D browser game.
- Create an explorable tropical island environment.
- Implement third-person player movement.
- Add interactive objects and collectibles.
- Design a multi-stage puzzle progression system.
- Implement health and hazard mechanics.
- Create a complete game-state flow.
- Support desktop and mobile controls.
- Deploy the game as a production web application.

# ✨ Features

## 🌴 3D Island World

The game contains a procedural low-poly tropical environment featuring:

- 🏖️ Beach
- 🌊 Ocean
- 🌴 Jungle
- 🏛️ Ancient Ruins
- 🕳️ Mysterious Cave
- 🛕 Treasure Temple
- 🌿 Vegetation
- 🪨 Rocks and environmental objects
- ☁️ Atmospheric environment

---

## 🧍 Third-Person Player

The player can explore the island using a third-person character controller.

### Movement

- Walk
- Run
- Jump
- Smooth camera follow
- Directional movement
- Collision-aware movement

### Desktop Controls

| Action | Keyboard |
|---|---|
| Move Forward | `W` / `↑` |
| Move Backward | `S` / `↓` |
| Move Left | `A` / `←` |
| Move Right | `D` / `→` |
| Run | `Shift` |
| Jump | `Space` / `Enter` |
| Interact | `E` |
| Pause | `P` |
